# Practice

Open **Practice** in the menu bar and choose **Words**, **Lessons**, or **Voice Practice**. The window shows only the chosen activity. To choose another activity, return to the Practice submenu; the practice screen has no mode tabs or mode-switching shortcuts. The last selected activity is remembered when reopening the app or following a Practice link from Reference. **⌘O** opens Words.

**Lessons** restores the full English and C++ course. The course button beside the lesson title hides or shows the sidebar in a wide window; its visibility is remembered across lessons and reopening. The sidebar includes language choices, search, unit headings, and completion markers. In a narrow window, that button opens a bounded course popover. Choose a lesson, read the introduction, then type the passage; the progress bar follows the matching text. The first use of each newly taught combination automatically shows its keys; later uses require **Hint**. Earlier completed lessons and the last lesson use their original saved progress; older curriculum progress migrates automatically. Completing a passage with released chords marks that lesson practiced and opens a centered results dialog with course progress and an **Up next** preview. **Next lesson** (Return or ⌘Return) advances only after completion; **Try again** (⌘R) restarts. The final lesson in either language offers **Back to course**. Escape closes the dialog, and **View results** reopens it. The restart icon in the lesson header is available during practice. This completion records practice, not delayed retention.

**Voice** reads ten words with macOS speech synthesis for eyes-closed chord practice. A correct released-chord answer gets spoken confirmation and automatically moves to the next word. Wrong answers get spoken correction guidance and stay on the current word. **Hear again** (⇧⌘R) repeats the prompt. **Hint** (⇧⌘H) reveals the current answer and speaks only the chord key names, with a pause between chords; that word is counted as assisted. The following answer stays hidden until another hint is requested. The final summary is spoken, and ⌘R starts a new session. Speech stops when the window loses focus, closes, or changes section. No microphone permission is needed. If no English voice is available, the window reports it and shows the answer so the failure is visible. A changed chord mapping starts a fresh spoken session.

New profiles start in **Words** with ten common English words. Every activity keeps the keyboard visible below the typing box. **Hint** (⇧⌘H) reveals the keys and combination for the current word while keeping the typing field focused. It follows that word's remaining chords, including suffix rewrites, and clears on the next word. Repeated requests reveal the same word; there is no persistent hints toggle. Hold the highlighted keys together, then release every key to produce the chord. Right Option switches between chords and ordinary typing.

Choose a word count or a timer and a vocabulary: English (200 common words), English 5k (5,000), or English 25k (24,141). Vocabulary sources and licenses are in `Resources/WordLists`. Existing word-session preferences carry over.

The first inserted character starts the clock. Space moves to the next word, including a mistyped word. The passage wraps to the available width and keeps the active word visible as you type, correct text, or resize the window. A word session also finishes when the final word is correct, without a trailing space. Timed sessions keep running through idle time and focus changes. All activities use the window width, and keyboard hints scale with the workspace.

The screen shows WPM, accuracy, and words or seconds remaining. Results include raw WPM and the speed graph. WPM counts correct characters using five characters per word. Accuracy includes corrected mistakes; verified intermediate chord spellings such as `make` before `making` do not count as mistakes.

**New words** (⌘Return) samples fresh words. **Retry** (⌘R) repeats the same passage. Paste and drag/drop cannot complete a session. Text and results stay in memory; only session preferences are saved.

Practice needs no system permissions. **Enable Typing in Other Apps…** remains a separate explicit choice; existing grants and choices are preserved.

The menu has **Reference**, **Custom Chords**, and **Settings**. **Chord Typing · Right ⌥** identifies the Option key on the right of the space bar. The selected language remains checked when chord typing is off. Settings includes the keyboard overlay, keyboard geometry, and printed/meaning/both key labels. Right Option tap timing stays internal, preserving any saved value and defaulting to 400 ms. File-management, reload, keyboard-check, and rollover-limit controls are removed. Existing mappings and keyboard reports remain readable.

Open **Custom Chords** to add a word, phrase, or symbol. Click the recorder, hold the keys together, then release all keys; enter the text and choose English, C++, or both. **Find unused chord** offers combinations of up to three keys that have no current meaning in the selected languages, preferring fewer keys and less travel. Suggestions account for dictionary entries, generated syllables, fingerspelling, numbers, active custom chords, and known keyboard limitations. They are suggestions to try, rather than a guarantee of physical comfort or registration.

The **Before → After** card shows the current and proposed output for every affected language and combination, including keys or languages restored by moving an existing chord. A replacement uses the **Replace chord** action and explains how to recover the original meaning. Built-in actions, Space, unsupported keys, active duplicate assignments, and combinations known to be blocked by the keyboard cannot be enabled.

**Try chord** focuses a local test area using the unsaved draft and the same engine as real typing. Try repeated presses, punctuation, and neighboring chords to check spacing. For a chord used in both languages, the test language menu switches between English and C++. Changing the draft or test language clears the test; **Clear** starts again. Right Option switches to ordinary typing. Test text stays in memory and never changes the saved mapping. The global router remains paused while the custom editor has focus.

**Words & phrases** adds normal word spacing and capitalization. **No added spaces** attaches the entered text on both sides; Caps Lock still uppercases it. This replaces the misleading “Exact text” label while retaining the saved `exact` spacing value and existing output behavior.

Click **Save chord** or **Replace chord** to apply changes immediately to Practice, Reference, the overlay, and typing in other apps. To pause a customization, uncheck **Enabled when saved** and save. The original mapping returns while the keys and text remain in the library; re-enable and save to use it again. Disabled chords can share keys, but enabling one checks for active duplicates. Library rows show **On**, **Off**, or **Needs repair**, with a detailed explanation when selected. **Remove chord** restores the installed meaning; **Undo remove** recovers it. Search matches text, physical keys, or language. Unsaved edits are retained after a save failure, and leaving a draft offers Save/Discard/Keep Editing. Customizations live in a separate `custom-chords.json` file; the installed mapping files are unchanged. Version 1 customizations load as enabled; version 2 persists the enabled state and prevents older app versions from silently re-enabling paused entries. Unreadable saved customizations are reported and never silently overwritten. Updating a mapping retains the current practice passage, input, timing, and results.

Validation: `scripts/test.sh`, `scripts/test-practice-ui.sh`, and `scripts/test-local-input.sh`.
