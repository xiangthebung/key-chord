# English word lists

Word Sprint bundles the English, English 5k, and English 25k vocabulary data from [Monkeytype](https://github.com/monkeytypegame/monkeytype). No network access is needed during practice.

Upstream word-list data is distributed under GNU GPL version 3; the unmodified license is included as `COPYING`. The lists are whitespace-packed in `Sources/KeyChordCore/EnglishWordLists.swift` with word order and spelling preserved.

Downloaded October 7, 2026. English 25k is the upstream vocabulary name; its current curated list contains 24,141 distinct words.
