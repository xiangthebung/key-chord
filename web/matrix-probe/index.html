KeyChord Matrix Probe for US (ANSI) keyboards

Every test is a 3-key combination: two keys held with one hand, plus the highlighted key tapped with the other. Tap the highlighted keys once each, in order; the highlight moves by itself. Green (✓): all three registered. Red (✗): blocked, the keyboard dropped it. If a key stays dark, just tap the next one. If the round can't finish because every key left is blocked, press Backspace to end it. Later rounds only ask for keys whose result isn't known yet, so they get short. Then a few 4-6 key chords confirm the map. About 10 minutes in all; progress is saved in this browser as you go. Use the US input source (any US layout works: only the key position matters).
